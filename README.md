##  Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/python-django-piscine.git
```

Move into the project:

```bash
cd python-django-piscine
```

---

## 🐍 Python Environment

It is recommended to use a virtual environment for Python projects.

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

### Linux / macOS

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

## 📦 Installing Dependencies

If a project contains a `requirements.txt` file, install the dependencies using:

```bash
pip install -r requirements.txt
```

---

## 🌐 Running Django Projects

For exercises that use Django:

```bash
python manage.py runserver
```

Then open your browser and visit:

```text
http://127.0.0.1:8000/
```
